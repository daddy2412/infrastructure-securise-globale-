Featured project — Homelab SOC

A virtualized and monitored IT infrastructure built at home to practise systems administration, detection engineering and cybersecurity operations.

  • OPNsense perimeter firewall and Hyper-V virtualization across two physical hosts.
  • Security stack including Wazuh SIEM/XDR, Security Onion network detection and Huntress endpoint protection.
  • Infrastructure monitoring with Grafana and Prometheus.
  • Public-facing services routed through Cloudflare Zero Trust, designed to avoid open inbound firewall ports.
  • Active Directory, Microsoft Intune, role-based access control and a dedicated backup server.
  • PowerShell automation for repeatable administration and deployment tasks.
