Featured project — Homelab SOC

A complete, monitored, and virtualized IT infrastructure, built and run from home to practice real detection engineering — not just certifications.

  • OPNsense perimeter firewall with Hyper-V virtualization in high availability across two physical hosts.
  • Full SOC stack: Wazuh for SIEM/XDR, Security Onion for network detection, Huntress for endpoint detection.
  • Real-time monitoring with Grafana and Prometheus.
  • Public-facing services exposed securely through Cloudflare Zero Trust — zero open inbound ports.
  • Role-based access control and Microsoft Intune for device and identity management, plus a dedicated SVR_BACKUP server for backup and recovery — all provisioned and configured through PowerShell scripts rather than manual setup.
  • Simulated brute-force attacks used to validate detection and alerting end to end.

Featured project — GenIA C21 Virtual Assistant

Built and deployed a bilingual (EN / FR) virtual assistant for Century 21 Gold Key Realty in Steinbach, Manitoba — live at c21assistant.daddyconnectit.com. It answers questions about housing, manages the waiting list, handles problem reports, and includes an admin dashboard.

  • Python application served by Gunicorn, containerized with Docker and Docker Compose, with Kubernetes manifests (deployment, ingress, secrets template).
  • Published through a Cloudflare Tunnel — zero open inbound ports; a systemd override makes the tunnel recover on its own after a reboot.
  • Hosted on an Ubuntu VM in a Hyper-V lab with an Active Directory domain (six Windows and Linux VMs); private ZeroTier network and SSH keys for administration.
  • Monitored with Zabbix, Wazuh, Prometheus + Grafana, and Loki + Alloy; noisy alerts tuned out so only useful ones remain.
  • Ransomware-style detection using a Wazuh decoy folder and a custom level-12 rule, tested end to end.
